# NAgorà Gestore 2.0

Nuova web app gestore mobile-first per prenotare spazi, organizzare corsi, gestire iscritti, wallet, chat e notifiche.

## Avvio locale

```powershell
npm ci
npm start
```

Applicazione: `http://localhost:4600`

## Build

```powershell
npm run build
```

Output: `dist/nagora-gestore-v2/browser`

La V2 usa le stesse API della web app gestore esistente e non sostituisce la cartella `frontend-gestore`.
